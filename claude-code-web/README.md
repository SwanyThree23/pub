## 🔄 8-Task Master Workflow

The **master workflow** keeps **8 types of tasks running at all times** for maximum productivity.

### Task Breakdown

| # | Task Type | Model | Purpose | Token Usage |
|---|-----------|-------|---------|-------------|
| 1-4 | **Small Features** | Haiku 4.5 | Add discrete functionalities | Low |
| 5 | **Product Management** | Sonnet 4.5 | Strategic planning & roadmap | Medium |
| 6 | **Marketing** | Sonnet 4.5 | Content creation & promotion | Medium |
| 7 | **Code Optimization** | Sonnet 4.5 | Performance improvements | Medium |

### 📦 Tasks 1-4: Small Feature Building

**Goal:** Rapidly add discrete, non-overlapping features

**Model:** Haiku 4.5 (cost-effective for simple tasks)

**Guidelines:**
- Keep features **small and focused**
- Ensure **no overlap** to avoid conflicts
- Target **quick wins** and improvements

**Example Prompts:**

```markdown
# Feature 1: Folder System
Build a folder organization system for the journal entries.
Users should be able to:
- Create folders
- Organize entries into folders
- Drag and drop to move entries
Use the existing tech stack (Next.js, TypeScript, Tailwind)
```

```markdown
# Feature 2: Color Coding
Add color coding capability to journal entries.
- Each entry can have a color assigned
- Show colored indicator next to entry title
- Add color picker in the editor interface
```

```markdown
# Feature 3: Entry Titles
Add automatic title generation for journal entries.
- Extract first line or first 50 characters as title
- Display title in the sidebar list
- Allow manual editing of titles
```

```markdown
# Feature 4: Social Sharing
Add social media share buttons for journal entries.
- Share to Twitter, Facebook, LinkedIn
- Generate shareable links
- Include privacy controls
```

## 🚀 Setup Guide

### Prerequisites

- **GitHub Account** (free)
- **Claude Code Extension** for VS Code
- **Claude Code for Web Access** (claude.ai)
- **Claude iOS App** (optional, for mobile workflow)

### Step 1: Initial Project Setup

```bash
# 1. Create your project locally with Claude Code in VS Code
# Use prompt: "Build [your app description with tech stack]"

# 2. Test locally
cd your-app
npm install
npm run dev

# 3. Create GitHub repository
# Go to github.com → New Repository → Create

# 4. Upload code via Claude Code
# Prompt: "Can you upload this code to [github-repo-url]"
```

### Step 2: Connect to Claude Code for Web

1. Go to **claude.ai**
2. Click **"Code"** section
3. Click **connection button**
4. Sign in with GitHub
5. Select your repository

### Step 3: Launch Master Workflow

Use the provided task templates to spin up all 8 tasks:

```bash
# Copy from templates/task-prompts/
- feature-1-prompt.md
- feature-2-prompt.md
- feature-3-prompt.md
- feature-4-prompt.md
- product-management-prompt.md
- marketing-prompt.md
- code-optimization-prompt.md
- security-check-prompt.md
```

Paste each into a separate Claude Code for Web session.

### Step 4: Automate Integration

```bash
# Install automation scripts
cd claude-code-web
npm install

# Set up git hooks
./scripts/setup-integration.sh

# Configure automation
cp config.example.json config.json
# Edit with your settings
```

## 🧠 Model Selection

### Choosing Between Haiku 4.5 and Sonnet 4.5

| Task Type | Recommended Model | Reason | Token Impact |
|-----------|------------------|---------|--------------|
| Simple features | **Haiku 4.5** | Efficient, cost-effective | ⭐ Low |
| Bug fixes | **Haiku 4.5** | Straightforward solutions | ⭐ Low |
| UI tweaks | **Haiku 4.5** | Clear requirements | ⭐ Low |
| Research | **Sonnet 4.5** | Deep analysis needed | ⭐⭐ Medium |
| Strategy | **Sonnet 4.5** | Complex reasoning | ⭐⭐ Medium |
| Writing | **Sonnet 4.5** | Creativity required | ⭐⭐ Medium |
| Optimization | **Sonnet 4.5** | Comprehensive review | ⭐⭐ Medium |
| Security | **Sonnet 4.5** | Critical analysis | ⭐⭐⭐ High |

### Model Selection Guide

**Use Haiku 4.5 when:**
- Task scope is well-defined and small
- Implementation is straightforward
- Similar examples exist in codebase
- Speed is more important than depth

**Use Sonnet 4.5 when:**
- Task requires strategic thinking
- Creative solutions needed
- Security or quality is critical
- In-depth analysis required
- Writing compelling content
- Complex code review

### Token Optimization Strategy

```
Morning: Launch 4 features with Haiku (low token usage)
         ↓
Review & integrate features
         ↓
Afternoon: Launch 2 research tasks with Sonnet (targeted usage)
           ↓
Evening: Launch optimization + security with Sonnet (critical tasks)
         ↓
Before bed: Queue next day's Haiku tasks
```

## 💡 Best Practices

### 1. Keep Features Disparate (Non-Overlapping)

**Good:**
```
✅ Task 1: Add folder system
✅ Task 2: Color code entries
✅ Task 3: Add export button
✅ Task 4: Improve mobile menu
```

**Bad:**
```
❌ Task 1: Redesign sidebar
❌ Task 2: Update sidebar colors (CONFLICT!)
❌ Task 3: Add sidebar animations (CONFLICT!)
❌ Task 4: Sidebar search feature (CONFLICT!)
```

### 2. Start Small, Scale Gradually

```
Day 1: Test workflow with 2-3 tasks
       ↓
Day 2-3: Expand to 5-6 tasks
         ↓
Week 2: Full 8-task workflow
        ↓
Optimize: Find your ideal balance
```

### 3. Maintain Momentum

**Morning Routine:**
```
1. Review overnight completions (5 min)
2. Test and integrate code (20 min)
3. Commit to main (5 min)
4. Launch new feature tasks (10 min)
```

**Evening Routine:**
```
1. Queue research tasks (5 min)
2. Launch optimization check (5 min)
3. Spin up security audit (5 min)
4. Queue 2-3 feature tasks for morning
```

### 4. Leverage Research Outputs

```
Product Roadmap Output
         ↓
Extract top 3 features
         ↓
Create feature task prompts
         ↓
Spin up as new tasks
```

```
Marketing Content Output
         ↓
Review and schedule tweets
         ↓
Use insights to inform features
         ↓
Create user-focused improvements
```

### 5. Document Everything

Keep a log:
```markdown
## Week of [Date]

### Completed
- ✅ Folder system (Task ID: abc123)
- ✅ Color coding (Task ID: def456)
- ✅ Export functionality (Task ID: ghi789)

### In Progress
- 🔄 Search feature (Task ID: jkl012)
- 🔄 Dark mode (Task ID: mno345)

### Backlog (from product roadmap)
- 📋 User profiles
- 📋 Cloud sync
- 📋 Collaboration features
```

### 6. Balance Speed and Quality

**Fast Iteration:**
- Use Haiku for quick features
- Test minimally for small changes
- Commit frequently

**Quality Focus:**
- Use Sonnet for critical tasks
- Thorough testing for security
- Code review for optimizations

### 7. Mobile Ideation Habits

- Keep app easily accessible
- Create prompt templates
- Voice-to-text for convenience
- Don't overthink - just launch tasks
- Review in batches, not individually
