# Research Tasks (5-6)

Use **Sonnet 4.5** model for in-depth strategic thinking and creative content.

---

## Research Task #5: Product Management

### Purpose
Strategic planning, feature roadmapping, user research, and product vision

### Model: Sonnet 4.5

---

### Template: Comprehensive Product Roadmap

```markdown
You are an expert product manager with 10+ years of experience building successful applications.

## Context

**Application Details:**
- **Name:** [Your App Name]
- **Description:** [Brief description of what your app does]
- **Target Users:** [Who uses your app - demographics, use cases]
- **Current Stage:** [MVP / Beta / Launched / Growth]
- **Tech Stack:** [Your technology stack]

**Current Features:**
1. [Feature 1]
2. [Feature 2]
3. [Feature 3]
4. [Feature 4]
5. [Feature 5]

**Pain Points / User Feedback:**
- [Known issue or user request #1]
- [Known issue or user request #2]
- [Known issue or user request #3]

**Business Goals:**
- [Goal 1: e.g., increase user retention]
- [Goal 2: e.g., expand to mobile]
- [Goal 3: e.g., monetization]

## Your Task

Create a comprehensive product roadmap that includes:

### 1. NOW (Next 30 Days)
**Focus: Quick wins and critical fixes**

For each item, provide:
- Feature name
- User value / business impact
- Estimated implementation complexity (Low/Medium/High)
- Priority (P0 = Critical, P1 = High, P2 = Medium)
- Success metrics

Example format:
```
**Feature: Advanced Search**
- **Value:** Users can find entries 5x faster
- **Complexity:** Medium (3-5 days)
- **Priority:** P1
- **Success Metric:** 60%+ users use search weekly
```

### 2. NEXT (30-90 Days)
**Focus: Major features and differentiators**

Include:
- Strategic features that set us apart
- Platform expansions (if applicable)
- User experience improvements
- Integration opportunities

### 3. LATER (90+ Days)
**Focus: Vision features and innovation**

Include:
- Moonshot ideas
- Advanced capabilities
- Market expansion features
- Strategic partnerships

### 4. Feature Prioritization Framework

Create a priority matrix based on:
- **User Impact:** How many users benefit? How much?
- **Business Value:** Revenue, retention, growth impact
- **Implementation Effort:** Dev time, complexity, dependencies
- **Strategic Alignment:** Fits long-term vision?

Provide priority scores for top 10 features.

### 5. Competitive Analysis

Analyze 3-5 competitors:
- **Competitor:** [Name]
  - Strengths: [What they do well]
  - Weaknesses: [What they lack]
  - Our Advantage: [How we differentiate]
  - Opportunities: [What we can learn/adapt]

### 6. User Personas

Define 2-3 primary user personas:
- Name, role, demographics
- Goals and motivations
- Pain points
- How our app serves them
- Feature priorities for this persona

### 7. Growth Strategy

Recommendations for:
- User acquisition channels
- Retention tactics
- Monetization opportunities
- Viral/referral mechanisms
- Community building

### 8. Success Metrics & KPIs

Define measurable goals:
- User metrics (DAU, MAU, retention)
- Engagement metrics (session time, frequency)
- Feature adoption rates
- Business metrics (revenue, conversion)

### 9. Risk Assessment

Identify potential risks:
- Technical risks
- Market risks
- Competition risks
- Resource constraints
- Mitigation strategies

### 10. Actionable Next Steps

Provide concrete next steps:
1. Immediate actions (this week)
2. Short-term initiatives (this month)
3. Long-term planning (this quarter)

## Output Format

Deliver as a well-structured markdown document with:
- Clear headings and sections
- Tables for prioritization matrices
- Bullet points for clarity
- Bold for emphasis
- Emoji for visual organization (optional)

Be specific, actionable, and data-driven where possible.
```

### Template: Feature Prioritization Only

For a quicker, more focused task:

```markdown
You are a product manager specializing in feature prioritization.

## Context
- **App:** [Your App Name]
- **Current Features:** [List]
- **Proposed Features:** [List 10-15 feature ideas]

## Your Task

Prioritize these features using the RICE framework:

**RICE Scoring:**
- **Reach:** How many users will this impact?
- **Impact:** How much will it improve the experience? (3=massive, 2=high, 1=medium, 0.5=low)
- **Confidence:** How sure are we? (100%=high, 80%=medium, 50%=low)
- **Effort:** Person-weeks to implement

**Score = (Reach × Impact × Confidence) / Effort**

### Output Format

| Feature | Reach | Impact | Confidence | Effort | RICE Score | Priority |
|---------|-------|--------|------------|--------|------------|----------|
| [Name]  | 1000  | 3      | 80%        | 2      | 1200       | 1        |

Then provide:
1. Top 5 features to build next (with rationale)
2. Features to postpone (with rationale)
3. Features to skip (with rationale)
```

### Template: User Research & Insights

```markdown
You are a user researcher analyzing application usage patterns.

## Context
- **App:** [Your App Name]
- **User Base:** [Size and description]
- **Available Data:** [What data you have - analytics, feedback, etc.]

## Your Task

Conduct a comprehensive user research analysis:

### 1. User Journey Mapping
Map out the typical user journey:
- First-time user experience
- Daily active user pattern
- Power user workflow
- Identify friction points in each stage

### 2. User Needs Analysis
- Core needs our app addresses
- Unmet needs (opportunities)
- Jobs-to-be-done framework analysis

### 3. Feature Usage Analysis
- Most used features
- Underutilized features (why?)
- Feature combinations
- Missing feature gaps

### 4. User Sentiment
- Common praise themes
- Common complaint themes
- Feature requests frequency
- Churn reasons (if known)

### 5. Recommendations
Based on research, recommend:
- Quick improvements (low-hanging fruit)
- Strategic feature additions
- Features to deprecate
- UX improvements
- User education needs

### 6. Research Methodology Suggestions
How to gather more insights:
- Survey questions to ask
- Analytics to track
- User interviews to conduct
- A/B tests to run

## Output Format
Structured markdown with:
- Executive summary
- Key findings
- Actionable recommendations
- Supporting data/reasoning
```

### Template: Social Media Content Creation

For focused content generation:

```markdown
You are a social media content creator specializing in tech/app marketing.

## Context
- **App:** [Your App Name]
- **Value Proposition:** [What problem it solves]
- **Target Audience:** [Who uses it]
- **Platform Focus:** [Twitter / LinkedIn / Facebook / Instagram]

## Your Task

Create a comprehensive social media content package:

### Twitter Content (20 tweets)

Create 20 tweet variations covering:

**Feature Highlights (5 tweets):**
- Each tweet highlights one key feature
- Include benefit-focused language
- Use emojis strategically
- Add relevant hashtags
- Keep under 280 characters

Example format:
```
✨ Organize your thoughts effortlessly with our new folder system

Say goodbye to endless scrolling 👋

Create folders, drag-and-drop entries, and find what you need instantly 🚀

Try it now: [link]

#productivity #organization #journaling
```

**User Benefits (5 tweets):**
- Focus on outcomes, not features
- Use before/after framing
- Include social proof elements

**Tips & Tricks (5 tweets):**
- How-to content
- Quick tips
- Power user features

**Engagement Tweets (5 tweets):**
- Questions to audience
- Polls
- User story requests

### LinkedIn Posts (5 posts)

Create 5 longer-form LinkedIn posts:

**Professional Angles:**
- Productivity improvements
- Work-life balance
- Professional development
- Industry insights

Format for each:
- Hook (first line)
- Story or insight (3-5 paragraphs)
- Call-to-action
- Relevant hashtags (3-5)

### Facebook Posts (3 posts)

Create 3 Facebook posts:
- More casual tone
- Community-focused
- Include questions
- Encourage sharing

### Content Themes

Organize all content by theme:
- 🎯 **Problem-Solution:** How the app solves real problems
- ✨ **Feature Spotlight:** Highlighting specific capabilities
- 💡 **Tips & Tricks:** How to get the most out of the app
- 📈 **Success Stories:** User wins and testimonials

Provide:
- 10 primary hashtags (use consistently)
- 20 secondary hashtags (rotate)

- Trending hashtag opportunities

### Visual Content Suggestions

For each post type, suggest:
- Image style (screenshot, graphic, photo)
- Color scheme
- Text overlay ideas
- Video concepts (if applicable)

### Posting Schedule

Recommend:
- Best times to post
- Frequency per platform
- Cross-posting strategy
- Evergreen vs. timely content mix

## Output Format

Deliver all content ready to post:
- Copy-paste ready
- Character counts noted
- Hashtags included
- Visual suggestions noted
- Organized by platform and theme
```

---

## Using Research Outputs

### From Product Roadmap:
```
1. Review roadmap output
2. Extract top 3-5 features
3. Create feature task prompts
4. Spin up as Tasks #1-4
5. Iterate based on learnings
```

### From Marketing Content:
```
1. Review generated content
2. Edit for brand voice
3. Schedule posts
4. Track engagement
5. Refine messaging based on performance
```

### Continuous Loop:
```
Research Tasks → Insights → Feature Tasks → Launch → Feedback → Research Tasks
```

---

**Pro Tip:** Run product management and marketing tasks every 1-2 weeks to maintain strategic momentum alongside tactical development.
