## 🚀 Quick Start (30 Minutes)

### Prerequisites

- [ ] **Google Account** (for NotebookLM)
- [ ] **Chrome Browser**
- [ ] **Anthropic Claude API Key**
- [ ] **N8N Instance** (self-hosted or cloud)
- [ ] **Social Media API Keys** (for distribution)

### Step 1: Install Chrome Extensions

```bash
# 1. Grabbit (URL Collector)
# Visit: chrome.google.com/webstore
# Search: "Grabbit"
# Click: Add to Chrome

# 2. NotebookLM Web Sync (Content Bridge)
# Visit: chrome.google.com/webstore
# Search: "NotebookLM Web Sync"
# Click: Add to Chrome
```

### Step 2: Configure Grabbit

1. Click Grabbit extension icon
2. Go to "More settings"
3. Add new action:
   - **Key:** Option/Alt
   - **Mouse:** Left click
   - **Visual:** Lime green box
   - **Action:** Copy URLs
4. Save settings

### Step 3: Create NotebookLM Notebook

1. Go to [notebooklm.google.com](https://notebooklm.google.com)
2. Click "Try Notebook LM"
3. Create new notebook (e.g., "Alex Hormozi AI")
4. You're ready to import!

### Step 4: Clone Your First Channel

**Import Videos:**
```
1. Navigate to target YouTube channel
2. Go to "Videos" tab
3. Hold Option + Left Click
4. Drag selection box over videos
5. URLs auto-copied to clipboard
```

**Transfer to NotebookLM:**
```
1. Click NotebookLM Web Sync extension
2. Select your notebook
3. Paste URLs
4. Click "Import URLs"
5. Wait for processing (few minutes)
```

### Step 5: Test the AI

```
In NotebookLM, ask:
"What advice would [Creator] give about [Your Problem]?"

Example:
"What advice would Hormozi give about hiring a video editor?"

The AI will synthesize responses in the creator's style!
```

## 🔒 Legal Compliance

### ⚠️ CRITICAL: Fair Use Requirements

**You MUST satisfy all 4 Fair Use factors:**

#### 1. Purpose & Character
✅ **DO:**
- Educational commentary
- Critical analysis
- Transformative derivative works
- Add 30%+ new insights

❌ **DON'T:**
- Exact transcript republication
- Replace original video
- Commercial use without transformation

#### 2. Nature of Work
⚠️ **Note:** YouTube videos are creative works (higher protection)

**Strategy:** Focus on educational/factual content

#### 3. Amount Used
✅ **Limits:**
- Direct quotes: Max 150 words per video
- Paraphrased concepts: Unlimited (with attribution)
- Timestamps: Unlimited
- Visual content: Never reproduce

#### 4. Market Effect
🎯 **Requirement:** Must increase creator's value

**Implementation:**
- Link to original videos
- Frame as "supplemental guides"
- Drive traffic TO creator
- Track referral metrics

### Attribution System

**Every piece of content MUST include:**

```markdown
---
📚 Inspired by [Creator Name]'s expertise
🎥 Original video: [URL]
💡 Used under Fair Use for educational commentary
---
```

**Code Implementation:**
```javascript
const ATTRIBUTION_TEMPLATE = {
  twitter: (creator, url) =>
    `\n\n💡 Insights from @${creator}\n🎥 Full video: ${url}`,

  linkedin: (creator, url) =>
    `\n\nBased on ${creator}'s content: ${url}\n#ThoughtLeadership`,

  blog: (creator, url) =>
    `<div class="attribution">
      <p>This analysis based on
         <a href="${url}">${creator}'s video</a></p>
      <p>Used under Fair Use for educational purposes</p>
    </div>`
};
```

### Claude API Optimization (60-80% savings)

#### Strategy 1: Prompt Compression

**Before:** 2,500 tokens per request
**After:** 800 tokens per request
**Savings:** $23/month

#### Strategy 2: Batch Processing

**Before:** Process each video individually
**After:** Batch 5 videos per request
**Savings:** $18/month (22% reduction)

#### Strategy 3: Caching Layer

**Implementation:**
```python
class ContentCache:
    def get_or_generate(self, video_id, platform):
        cache_key = f"{video_id}:{platform}"

        # Check cache
        if cached := redis.get(cache_key):
            return cached

        # Generate new
        content = claude_api.generate(video_id, platform)

        # Cache for 30 days
        redis.setex(cache_key, 30*24*60*60, content)

        return content
```

**Expected:** 40-60% cache hit rate
**Savings:** $40/month
